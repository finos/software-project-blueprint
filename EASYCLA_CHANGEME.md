This file is used to test EasyCLA onboarding.

To get started, [submit a pull request](https://github.com/finos/{PROJECT_SLUG}/edit/main/EASYCLA_CHANGEME.md) that changes this file (an extra line is enough). The EasyCLA bot comments on that pull request and states whether every contributor is covered by the project's **CLA**. If not, the bot posts instructions for signing.

On this blueprint repository, `{PROJECT_SLUG}` is `software-project-blueprint`. After you create a project from the template, delete this file, or keep it only while you are testing EasyCLA.

You can read more about EasyCLA on the [FINOS Community site](https://community.finos.org/docs/governance/Software-Projects/easycla). For how CLA relates to **DCO** and Labs defaults, see [Contribution Requirements](https://community.finos.org/docs/governance/Software-Projects/contribution-compliance-requirements).
