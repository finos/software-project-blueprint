## Updating this file

All changes to the Maintainer list, including election or removal of Maintainers and the TSC Chair, are managed openly:

- Any addition, removal, or update **MUST** be submitted as a **pull request** to this file.
- Maintainer and TSC Chair changes **MUST** be approved by a majority vote of the TSC.
- Document or link to the vote outcome in the pull request description or comments.
- This process creates a public audit trail of project leadership over time.

Please email **help@finos.org** whenever this file is updated with a change to maintainership.
